## What I build

- [**Bike Shop CX Agent**](https://github.com/jaredfontaine2002/bike-shop-cx-agent) —
  a working AI customer-service agent designed specifically for bike shops and
  DTC cycling brands: sizing and compatibility from the shop's own catalogue,
  WISMO and service status, warranty triage, a daily flag report for the owner,
  and 48h/5-day follow-ups. Guardrail-first design: it proposes, a human
  approves. Live demo linked in the repo.
- [**Neto Supplier Sync**](https://github.com/jaredfontaine2002/neto-supplier-sync) —
  a Python tool that reads supplier invoice/dispatch PDFs, matches them to the
  right Neto (Maropost) order, and writes tracking and parts back as safe
  internal notes — so staff can answer "where's that part?" from the order
  itself. Synthetic data only; 9/9 tests.
- [**Gorgias CX Analytics — Bike Shop**](https://github.com/jaredfontaine2002/gorgias-cx-analytics) —
  helpdesk analytics toolkit for a Gorgias instance: first-response /
  resolution / CSAT metrics, SLA breach tracking and staffing
  recommendations, broken down by bike-shop ticket tags.
- [**Bike Shop Sales Dashboard**](https://github.com/jaredfontaine2002/bike-shop-sales-dashboard) —
  end-to-end e-commerce analytics for a cycling retailer: synthetic 2-year
  order data, pandas analysis pipeline, interactive Streamlit + Plotly
  dashboard (KPIs, revenue trends, return-rate breakdowns).
